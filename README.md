# PreventScreenshotsInSWIFTUI

Sample code demonstrating Detect screenshots with a UIKit notification and keep sensitive SwiftUI content out of them. Tested on iOS 27, including the popular trick that doesn't work..

> This project accompanies the article: [Detect and Block Screenshots in SwiftUI](https://bleepingswift.com/blog/prevent-screenshots-in-swiftui)

## Requirements

- Xcode 27.1+
- iOS 26.0+
- Swift 6.0

## Getting Started

1. Clone this repository
2. Run `xcodegen generate` (requires [XcodeGen](https://github.com/yonaskolb/XcodeGen))
3. Open `PreventScreenshotsInSWIFTUI.xcodeproj`
4. Build and run
